# 🎬 Netflix Movies & TV Shows Analysis using EDA and K-Means Clustering

## Project Overview

This project performs Exploratory Data Analysis (EDA) and K-Means
Clustering on the Netflix Movies & TV Shows dataset.

## Features

-   Data Cleaning
-   Exploratory Data Analysis (EDA)
-   Data Visualization
-   K-Means Clustering
-   Cluster Visualization

## Technologies

-   Python
-   Google Colab
-   Pandas
-   NumPy
-   Matplotlib
-   Seaborn
-   Scikit-learn

## Dataset

`netflix_data.csv`

## Installation

``` bash
pip install -r requirements.txt
```

## Run

1.  Open the notebook in Google Colab.
2.  Upload `netflix_data.csv`.
3.  Run all cells.
